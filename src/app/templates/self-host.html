Self-host

One container on any VPS.

You need a VPS with SSH access, a domain pointed at it, and either Docker or Python 3.12+. Pick the path that fits how you like to run things.

Docker path

  1. Point your domain at the VPS and sign in over SSH.
  2. Install Docker and the compose plugin.
  3. Clone the repo and configure .env as on the get-started page.
  4. Seed once, then start: 
    uv run seed.py
docker compose up -d --build
  5. Put a reverse proxy (Caddy or nginx) in front for TLS and forward to localhost:8000. Keep ./data and .env mounted so restarts lose nothing.
  6. Adding sermons later is just uploading files: drop .pdf or .docx files into ./data and the watcher embeds them with no restart.

Bare-metal path

  1. Install Python 3.12 and uv on the VPS.
  2. Clone, configure .env, and seed: 
    uv sync
uv run download_kjv.py
uv run seed.py
  3. Run the web server: 
    uv run uvicorn src.app.main:app --host 0.0.0.0 --port 8000
  4. Run the watcher in a second process so new notes index themselves: 
    uv run python -m src.app.workers.watcher
  5. Keep both alive with systemd (two small units, restart=always), then terminate TLS with Caddy or nginx forwarding to port 8000.
  6. New sermons are just files: drop .pdf or .docx into the data folder and the watcher embeds them automatically.

Connect Telegram

curl -X POST "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<domain>/webhook/telegram&secret_token=<SECRET>"

Confirm health

curl https://<domain>/health

Expect {"status": "ok", "db": "ok"}. A 503 means the database file is missing or unreadable. Check the ./data mount.
