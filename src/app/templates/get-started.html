Get started

From clone to first answer.

Five steps. Copy each block, paste it in your terminal, move on.

1. Clone and configure

git clone <your-repo-url> sermon
cd sermon
cp .env.example .env

2. Add your keys

Open .env and fill in what you use. Start with embeddings and answers; add chat platforms when ready:

  • OPENAI_API_KEY: embeddings (primary)
  • LLM_BASE_URL, LLM_MODEL, LLM_API_KEY: answers (primary)
  • OPENROUTER_API_KEY: automatic fallback for both
  • TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET: Telegram later

3. Bundle the Bible text (optional, recommended)

uv run download_kjv.py

Skip this and verses are fetched on demand instead.

4. Add your sermons and index them

No special format needed. Drop your sermon .pdf or .docx files into data/, then index everything:

uv run seed.py

This repo's own notes use an optional dated-markdown style (data/2026-Sermons.md, set via SERMON_FILE_PATH). If that file isn't there, it's simply skipped. Your PDFs and Word docs are indexed either way. Safe to re-run: known files are skipped, edited ones are updated.

5. Run it

docker compose up -d

Prefer bare Python?

uvicorn src.app.main:app --reload

Check it works

curl localhost:8000/health
curl -X POST localhost:8000/query -H 'Content-Type: application/json' -d '{"question": "What was taught on the Spirit of Might?"}'

6. Keep the watcher running

Indexing stays automatic only while the watcher is up. In a second terminal, next to the server:

uv run python -m src.app.workers.watcher

Drop a PDF or Word doc into data/ and it gets embedded with no restart. On a VPS both processes stay up under systemd or Docker (see self-host).

Going further: run this on a VPS with TLS and the Telegram webhook.
